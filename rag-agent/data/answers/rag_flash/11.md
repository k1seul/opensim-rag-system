OpenSim에서 Scaling을 수행하기 위해 필요한 주요 파일들은 다음과 같습니다:

*   **Generic OpenSim 모델 파일 (`.osim`)**: 이는 대상 피험자의 인체 측정에 맞게 스케일링될 기본 근골격계 모델입니다 [3, 4, 5].
*   **Scale Tool 설정 파일 (`.xml`)**: 이 파일은 스케일링 프로세스에 필요한 모든 설정과 파라미터, 다른 입력 파일들의 경로 및 출력 선호도를 포함합니다 [3, 5].
*   **마커 데이터 파일 (`.trc`)**: 이 파일은 측정 기반 스케일링과 모델 마커를 피험자의 자세에 맞게 조정하는 데 사용되는 실험 마커 궤적 (일반적으로 정적 시험에서 얻은)을 포함합니다 [1, 5].

추가적으로, 다음 파일들은 특정 시나리오에서 선택적으로 사용될 수 있습니다:

*   **외부 마커 세트 파일 (`.xml`)**: 만약 일반 모델에 마커 세트가 포함되어 있지 않거나, 추가 마커를 모델에 포함시키고자 할 경우, 외부 마커 세트 파일을 로드할 수 있습니다 [5].
*   **좌표 데이터 파일 (`.mot`)**: 이 파일은 정적 자세에 대한 초기 관절 각도를 제공하여, 마커 조정을 위한 역기구학(Inverse Kinematics) 문제 해결에 도움을 줄 수 있습니다 [5].

OpenSim Scale Tool은 이러한 입력 파일들을 사용하여 일반 모델의 근골격계 형상과 관성 파라미터를 특정 피험자에 맞게 변경하며, 이는 후속 시뮬레이션 결과에 매우 중요한 영향을 미칩니다 [3].
