OpenSim에서 Static Optimization (SO)과 Computed Muscle Control (CMC)은 모두 측정된 움직임으로부터 근육의 힘이나 활성화를 추정하는 데 사용되는 역 문제(Inverse Problem) 해결 도구입니다. 그러나 이 두 가지 도구는 근육 역학 모델링 방식과 목표 출력에서 중요한 차이를 가집니다.

다음 표는 OpenSim에서 SO와 CMC의 주요 차이점을 비교합니다.

| 특징  | Static Optimization (SO)  | Computed Muscle Control (CMC)  |
| :----------------------- | :----------------------------------------------------------- | :----------------------------------------------------------------------------------------- |
| **목표**  | 측정된 움직임으로부터 개별 근육 힘 및 활성화 추정 [4]  | 측정된 움직임에 따라 모델을 구동할 근육 흥분(excitation) 추정 [1, 4]  |
| **근육 역학 모델링**     | 근육 흥분-활성화(excitation-activation) 역학을 무시함 [5]. 각 시간 단계에서 근육 활성화만 추정함. | 근육 흥분-활성화 역학을 고려함 [4, 5]. 근육이 즉각적으로 힘을 생성할 수 없다는 사실을 모델링함 [5]. |
| **건(Tendon) 모델링**    | 강체 건(rigid tendons)을 가정함 [4, 5].  | 유연한 건(compliant tendons)을 지원함 [4, 5].  |
| **최적화 접근 방식**     | 각 시간 단계에서 활성화 제곱을 최소화하는 독립적인 정적 최적화 문제를 해결함 [4]. | 움직임을 10ms 윈도우로 나누고, 각 윈도우 내에서 움직임 추적에 필요한 근육 흥분을 계산하는 최적화를 수행함 [4]. 이는 동적 최적화에 가깝게 동작함. |
| **계산 속도**  | 빠름 [4].  | 느림 (근육 동역학 및 유연한 건 모델링, 윈도우 최적화로 인해).  |
| **주요 출력**  | 근육 힘, 근육 활성화 (.sto 파일) [4].  | 근육 흥분 (.sto 파일) [1, 4], 근육 활성화 (흥분 역학을 통해 계산됨) [5, 6].  |
| **전처리 단계**  | Inverse Dynamics 결과에 직접 적용 가능.  | 잔여력 감소 알고리즘(Residual Reduction Algorithm, RRA)을 먼저 실행하여 모델의 질량 중심을 조정하고 키네마틱스(kinematics)를 동적으로 일관성 있게 만드는 것이 권장됨 [4]. |
| **에너지 소비 모델링**   | 흥분과 활성화 변수가 분리되지 않아 에너지 소비 모델링에 제한적 [5]. | 흥분 및 활성화 변수가 분리되어 에너지 소비 모델링에 더 적합함 [5].  |
| **장기 건 동작 모델링**  | 강체 건 가정으로 인해 제한적 [5].  | 아킬레스 건과 같은 장기 건의 정확한 동작을 모델링하는 데 중요함 [5].  |

**실용적인 조언 및 고려사항:**

*   **SO 선택 시**: 계산 속도가 중요하고, 강체 건 가정 및 흥분-활성화 역학 무시가 특정 연구 목적에 허용 가능한 경우에 SO를 사용할 수 있습니다 [4]. 주로 각 시간 단계에서 근육 힘/활성화의 즉각적인 추정치가 필요할 때 유용합니다.
*   **CMC 선택 시**: 근육의 생리학적 행동을 더 정확하게 표현해야 할 때 CMC를 선택해야 합니다 [4]. 특히 근육 활성화 동역학이나 아킬레스 건과 같은 장기 건의 유연성(compliant tendons)이 움직임에 중요한 역할을 하는 경우에 필수적입니다 [5]. CMC는 또한 순방향 시뮬레이션(Forward Simulation)을 구동하기 위한 근육 흥분 값을 얻는 데 사용됩니다 [1, 4].
*   **RRA의 중요성**: CMC를 실행하기 전에 Residual Reduction Algorithm (RRA)을 사용하는 것이 일반적인 워크플로우입니다 [4]. RRA는 모델링 및 마커 데이터 처리 오류로 인해 발생하는 비물리적인 보상 힘인 "잔여력(residuals)"을 최소화하여, CMC 솔루션이 지면 반력 데이터와 더욱 동적으로 일관되도록 돕습니다 [4]. CMC 솔루션의 잔여력이 충분히 작은지 확인하는 것이 중요합니다 [4].
*   **초기 추정치로의 활용**: CMC 솔루션은 Moco(Direct Collocation)나 강화 학습(Reinforcement Learning)과 같은 더 복잡한 예측 시뮬레이션의 초기 추정치(initial guess)로 활용될 수 있어, 최적화 속도를 향상시킬 수 있습니다 [4].
