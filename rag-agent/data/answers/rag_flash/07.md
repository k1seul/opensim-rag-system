OpenSim에서 Static Optimization (SO)과 Computed Muscle Control (CMC)은 관찰된 동작의 역학을 생성하는 근육 활성화 및 근력을 추정하는 데 사용되는 두 가지 주요 최적화 기법입니다 [4]. 이 두 가지 방법은 근육 활동을 추정하는 방식에서 중요한 차이를 가집니다.

다음 표는 OpenSim의 SO와 CMC의 주요 차이점을 요약한 것입니다:

| 특징  | Static Optimization (SO)  |
| **목적**  | 주어진 동작의 위치, 속도, 가속도 및 외부 힘(예: 지면 반력)을 만족하는 근육 활성화 및 근력을 추정합니다 [1]. 관찰된 동작의 역학을 생성하는 근육 활성화를 해결합니다 [2].  |
| **방법론**  | 각 시간 프레임에서 계산이 수행되며, 시간 단계 사이에 운동 방정식을 통합하지 않습니다 [1, 2]. 근육 힘은 제곱(또는 다른 거듭제곱) 근육 활성화의 합을 최소화하여 해결됩니다 [3].  |
| **근육 활성화 다이내믹스** | **무시됩니다** [1]. 각 시간 프레임에서 독립적으로 계산되며, 이전 시간 단계의 활성화 상태가 현재 계산에 영향을 미치지 않습니다 [1, 2].  |
| **테이퍼링 (Tendon Compliance)** | **지원하지 않습니다** [5].  |
| **복잡성**  | 일반적으로 **빠르고 효율적**입니다 [5].  |

| **단점**  | *   **근육 활성화 다이내믹스 무시**: 근육이 순간적으로 힘을 생성할 수 없다는 사실을 모델링하는 데 중요한 근육 활성화 다이내믹스를 무시합니다 [1, 5].  |
| **단점**  | *   **활성화 다이내믹스 무시**: 근육 활성화의 동적 특성을 무시하여 근육이 즉각적으로 힘을 발생시킬 수 없다는 점을 반영하지 못합니다 [1, 5].  |
| **단점**  | *   **활성화 다이내믹스 무시**: 근육 활성화의 동적 특성을 무시하여 근육이 즉각적으로 힘을 발생시킬 수 없다는 점을 반영하지 못합니다 [1, 5].  |
