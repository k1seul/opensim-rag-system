OpenSim에서 `.c3d` 파일을 `.trc` 파일로 변환하는 것은 OpenSim 시뮬레이션 및 분석을 위해 마커 좌표 데이터를 준비하는 데 필수적인 단계입니다. OpenSim은 마커 좌표 데이터를 `.trc` 파일 형식으로만 읽을 수 있기 때문에, `.c3d`와 같은 다른 데이터 형식의 파일은 사용하기 전에 `.trc` 파일로 변환해야 합니다 [1, 3, 4].

OpenSim 4.0부터는 이러한 데이터 준비 과정을 간소화하는 새로운 도구들이 도입되었습니다 [1, 2, 4]. 여기에는 Matlab 스크립트와 Python 바인딩을 활용하는 방법이 포함됩니다.

---

### `.c3d` 파일을 `.trc` 파일로 변환하는 방법

다음은 `.c3d` 파일을 `.trc` 파일로 변환하는 단계별 지침입니다.

#### 1. 일반적인 데이터 준비 사항

`.c3d` 파일을 `.trc`로 변환하기 전에, OpenSim 모델과 호환되도록 몇 가지 사항을 준비해야 합니다.

*   **마커 이름 준비**: OpenSim은 `.trc` 파일의 실험 마커 데이터와 OpenSim 모델에 부착된 디지털 마커를 이름 일치를 통해 연결합니다 [1, 3, 4]. 따라서 `.trc` 파일의 마커 이름이 모델 마커 이름과 정확히 일치하는지 확인하는 것이 중요합니다 [3, 4].
    *   모션 캡처 시스템은 종종 "Subject36\_LASI"와 같이 피험자 식별자와 마커 위치를 포함하는 이름을 부여합니다 [4]. 이러한 피험자별 이름은 모델 마커 이름과 일치하지 않을 수 있으므로, 데이터 처리 중에 `.trc` 파일의 열 제목을 "LASI"와 같은 일반적인 이름으로 변경하는 것이 좋습니다 [4].
*   **좌표계 일치**: 모션 캡처 시스템이 OpenSim 모델에서 분석하려는 좌표계와 다른 좌표계로 데이터를 내보낼 수 있습니다 [4]. 연구실 좌표계가 모델 좌표계에서 회전된 경우, 분석 전에 좌표 변환이 필요합니다 [4].

#### 2. Matlab 스크립트를 사용하여 변환 (OpenSim 4.0 이상 권장)

OpenSim 4.0에는 `.c3d` 파일을 `.trc` 파일로 변환하는 데 사용할 수 있는 Matlab 스크립트가 포함되어 있습니다 [1, 2, 3, 4].

**단계별 지침:**

1.  **Matlab 환경 설정**: OpenSim Matlab 스크립트 환경을 설정해야 합니다. OpenSim 설치 시 제공되는 지침에 따라 Matlab 경로에 OpenSim 라이브러리를 추가했는지 확인하십시오.
2.  **`c3dExport.m` 스크립트 찾기**: OpenSim 4.0 설치 폴더 내의 `CodeExamples` 폴더에서 `c3dExport.m`이라는 Matlab 스크립트를 찾으십시오 [1, 2, 3, 4]. 이 스크립트는 `.c3d` 파일을 `.trc` 및 `.mot` 파일로 변환하는 예시를 제공합니다 [5].
3.  **스크립트 실행 및 `.c3d` 파일 지정**:
    *   Matlab에서 `c3dExport.m` 스크립트를 엽니다.
    *   스크립트 내에서 변환하려는 `.c3d` 파일의 경로와 이름을 지정합니다.
    *   스크립트에 따라 출력 `.trc` 파일의 이름과 경로를 설정합니다.
    *   스크립트를 실행하여 `.c3d` 파일을 `.trc` 파일로 변환합니다.

**일반적인 문제 및 해결책:**

*   **이름 없는 마커 오류**: `.c3d` 파일에 이름 없는 마커가 있는 경우 (예: `*119`), Matlab의 `osimTableToStruct` 함수에서 `Illegal Column label` 또는 `Invalid field name` 오류가 발생할 수 있습니다 [5].
    *   **해결책 1**: `.c3d` 파일에서 이름 없는 마커를 모두 삭제합니다 [5].
    *   **해결책 2**: `osimTableToStruct.m` 스크립트의 로컬 버전을 편집하여 `*` 문자를 'm'과 같은 다른 문자로 변경합니다 (예: `*119`를 `m119`로 변경) [5].

#### 3. Python 바인딩을 사용하여 변환

OpenSim은 Python 바인딩을 통해 `.c3d` 파일을 `.trc` 파일로 변환하는 기능을 제공합니다. `C3DFileAdapter` 클래스를 사용하여 이 작업을 수행할 수 있습니다 [6].

**단계별 지침:**

1.  **Python 환경 설정**: OpenSim Python 바인딩을 설치하고 환경을 설정해야 합니다.
2.  **BTK (Biomechanical Toolkit) 설치**: `C3DFileAdapter`는 내부적으로 C3D 파일 처리를 위해 BTK를 활용할 수 있습니다. Python 3.x 환경에서는 `conda`를 사용하여 설치할 수 있습니다 [6]:
    ```bash
    conda install -c conda-forge btk
    ``` [6]
3.  **`C3DFileAdapter` 사용**: 다음은 `.c3d` 파일을 읽고 `.trc` 파일로 쓰는 기본적인 Python 코드 예시입니다 [6].

    ```python
    import opensim as osim
    import os

    # C3D 파일 경로 설정
    c3d_dir = "path/to/your/c3d/files"
    c3d_file = "your_c3d_file.c3d"
    output_trc_file = "output_marker_data.trc"

    # C3DFileAdapter 객체 생성
    adapter = osim.C3DFileAdapter()

    # (선택 사항) 힘 표현 위치 설정 (필요한 경우)
    # adapter.setLocationForForceExpression(osim.C3DFileAdapter.ForceLocation_CenterOfPressure) [6]

    # C3D 파일 읽기
    # read() 메서드의 인자 수는 OpenSim 버전에 따라 다를 수 있습니다.
    # OpenSim 4.2 (beta) 기준으로는 파일 경로만 전달하는 것이 일반적입니다. [6]
    tables = adapter.read(os.path.join(c3d_dir, c3d_file))

    # 마커 데이터 테이블 추출 (일반적으로 'markers' 키로 접근)
    marker_table = tables.get('markers')

    # .trc 파일로 쓰기
    osim.TRCFileAdapter().write(marker_table, output_trc_file)

    print(f"'{c3d_file}'가 '{output_trc_file}'로 성공적으로 변환되었습니다.")
    ``` [6]

**일반적인 문제 및 해결책:**

*   **`TypeError: read() takes 2 positional arguments but 3 were given`**: `adapter.read()` 메서드에 전달하는 인자 수에 대한 오류가 발생할 수 있습니다 [6].
    *   **해결책**: OpenSim 버전에 따라 `adapter.read(os.path.join(c3d_dir, c3d_file))`와 같이 파일 경로만 전달하거나, 필요한 경우 `adapter.read(os.path.join(c3d_dir, c3d_file), 1)`과 같이 추가 인자를 전달해야 할 수 있습니다 [6]. OpenSim 4.2 (beta) 예시에서는 파일 경로만 전달합니다 [6].
*   **데이터 유형 문제**: `read()` 메서드 호출 후 반환되는 데이터 유형이 `common.StdMapStringAbstractDataTable`인 경우, 후속 데이터 처리에 문제가 발생할 수 있습니다 [6]. 이는 올바른 키(예: 'markers', 'forces')를 사용하여 개별 테이블을 추출해야 함을 의미합니다.

---

OpenSim에서 `.c3d` 파일을 `.trc` 파일로 변환하는 과정은 주로 마커 이름과 좌표계 일치에 대한 주의가 필요하며, 최신 OpenSim 버전의 Matlab 스크립트 또는 Python 바인딩을 활용하는 것이 가장 효율적입니다 [3, 4].
