OpenSim을 Python 및 Matlab 환경에서 스크립팅하기 위한 설정 방법은 다음과 같습니다.

---

### Matlab 스크립팅 환경 설정

OpenSim 4.0 이상 버전에서는 64비트 Matlab이 필요합니다 [4].

#### 1. 자동 설정 (권장)

Matlab에서 OpenSim 라이브러리를 설정하는 가장 빠르고 권장되는 방법은 `configureOpenSim.m` 스크립트를 사용하는 것입니다 [1, 3, 4].

*   **1단계: OpenSim 설치 디렉토리 확인**
    OpenSim이 설치된 경로를 찾습니다. Windows의 기본값은 `C:/OpenSim 4.0`입니다 [1].
*   **2단계: `configureOpenSim.m` 실행**
    Matlab을 시작하고 `OPENSIM_INSTALL_DIR/Resources/Code/Matlab` (예: `C:/OpenSim 4.0/Resources/Code/Matlab`) 또는 `C:opensim-core-4.4.1ResourcesCodeMatlab` [3] 경로에 있는 `configureOpenSim.m` 파일을 실행합니다 [1, 3, 4].
    *   이 스크립트는 이전에 설정된 OpenSim 설치를 Matlab에서 제거하며, 변경 사항을 백업합니다 [4].
    *   스크립트는 OpenSim 설치 디렉토리를 선택하라는 메시지를 표시할 수 있습니다 [1].
*   **3단계: 시스템 PATH 환경 변수 확인 (Windows 사용자)**
    Windows 사용자의 경우, `OPENSIM_INSTALL_DIR/bin` 디렉토리(예: `C:/OpenSim 4.0/bin`)가 시스템 PATH 환경 변수에 포함되어 있고, 다른 OpenSim 설치보다 우선하도록 설정되어 있는지 확인해야 합니다 [1, 3].
*   **4단계: Matlab 재시작**
    변경 사항을 적용하기 위해 Matlab을 재시작합니다 [1, 3]. OpenSim 라이브러리는 재시작하기 전까지 인식되지 않습니다 [1].
*   **5단계: 설정 확인**
    Matlab 명령 창에서 `>> org.opensim.modeling.opensimCommon.GetVersionAndDate()`를 실행하여 OpenSim 버전 및 날짜가 올바르게 표시되는지 확인합니다. 날짜는 2023년 7월이어야 합니다 [3].
    또한, `import org.opensim.modeling.*`를 실행하여 오류가 없는지 확인합니다 [5].

#### 2. 수동 설정 (OpenSim 3.1 또는 이전 버전의 경우)

OpenSim 3.1 또는 이전 버전을 사용하거나 자동 설정 스크립트에 문제가 있는 경우 수동으로 설정할 수 있습니다 [5].
**주의:** Matlab을 관리자 권한으로 실행해야 합니다 [5].

*   **1단계: OpenSim의 Java 라이브러리(.jar) 경로 추가**
    Matlab 명령 창에 `edit classpath.txt`를 입력하고, 파일 끝에 `OPENSIM_INSTALL_DIRECTORY\opensim\modules\org-opensim-modeling.jar` 경로를 추가합니다 [5].
*   **2단계: OpenSim의 C++ 라이브러리 경로 추가**
    Matlab 명령 창에 `edit librarypath.txt`를 입력하고, 파일 끝에 `OPENSIM_INSTALL_DIRECTORY\bin` 경로를 추가합니다 [5].
*   **3단계: Matlab의 PATH 변수에 OpenSim 유틸리티 디렉토리 추가**
    Matlab 명령 창에 `pathtool` (또는 이전 버전의 `editpath`)을 입력합니다 [4, 5].
    "Add Folder"를 클릭하여 `OPENSIM_INSTALL_DIRECTORY\bin` 경로를 추가합니다 [5].
    또한, `OPENSIM_INSTALL_DIR/Resources/Code/Matlab/Utilities` 디렉토리를 Matlab의 PATH 변수에 추가해야 합니다 [4].
*   **4단계: Matlab 재시작**
    모든 변경 사항을 적용하려면 Matlab을 닫고 재시작해야 합니다 [5].
*   **5단계: 설정 확인**
    Matlab 명령 창에서 `import org.opensim.modeling.*`를 입력하여 오류가 발생하지 않는지 확인합니다 [5].

#### Matlab 스크립팅 추가 정보

*   **라이브러리 로드:** 스크립트 시작 부분에 `import org.opensim.modeling.*`를 사용하여 OpenSim 라이브러리를 로드합니다 [5].
*   **클래스 메서드 확인:** `methods Model` 또는 `methods org.opensim.modeling.Model`을 사용하여 클래스의 모든 메서드를 볼 수 있습니다 [4, 5]. `methodsview Model`은 메서드 시그니처를 팝업 창으로 보여줍니다 [4, 5].
*   **유틸리티:** OpenSim은 C3D 파일 가져오기 (`osimC3D.m`), OpenSim Table과 Matlab Struct 간 변환 (`osimTableFromStruct.m`, `osimTableToStruct.m`) 등과 같은 일반적인 작업을 위한 유틸리티 함수를 제공합니다 [4].
*   **Geometry 경로 설정:** 모델을 로드할 때 Geometry 메시 파일을 찾지 못해 발생하는 경고를 피하려면 `OpenSim:ModelVisualizer()`의 Geometry 폴더 경로를 설정해야 합니다 [4].
*   **Matlab과 OpenSim 인덱싱:** Matlab은 1부터 인덱싱을 시작하지만 OpenSim 데이터 구조는 0부터 시작하므로 주의해야 합니다 [5].
*   **로그 메시지 표시:** OpenSim 4.2 이상 버전에서는 Matlab 명령 창에 OpenSim 로그 메시지가 표시되지 않는 경우 `org.opensim.modeling.Logger.addConsoleSink()` 명령을 실행하여 활성화할 수 있습니다 [4].

### Python 스크립팅 환경 설정

OpenSim Python 바인딩은 64비트 Python 버전과 호환됩니다 [6].

#### 1. Conda 패키지 사용 (가장 빠르고 권장)

OpenSim Python 스크립팅을 시작하는 가장 빠른 방법은 사전 빌드된 Conda 패키지를 설치하는 것입니다 [2, 6].

*   **1단계: Conda 설치 및 환경 생성**
    [Conda 사용자 가이드](https://conda.io/projects/conda/en/latest/user-guide/index.html)를 참조하여 Conda를 설치하고 터미널(또는 Anaconda prompt)에서 다음 명령어를 사용하여 새 Conda 환경을 생성하고 활성화합니다 [2, 6].
    ```bash
    conda create -n opensim_scripting python=3.11 numpy # 환경 이름은 변경 가능 [2]
    conda activate opensim_scripting
    ```
    *   **Mac Arm64 시스템 (M1, M2, M3 등) 사용자의 경우:** `libcxx` 최신 버전을 설치하기 위해 다음 명령어를 먼저 실행해야 할 수 있습니다 [6].
  ```bash
  conda install conda-forge::libcxx
  ```
*   **2단계: OpenSim 설치**
    Conda 환경을 생성하고 활성화한 후, 다음 명령어를 사용하여 환경과 호환되는 OpenSim 최신 버전을 설치합니다 [6].
    ```bash
    conda install -c opensim-org opensim
    ```
    *   **특정 버전 설치:** [Anaconda.org](https://anaconda.org/opensim-org/opensim/files)에서 원하는 버전의 패키지 이름을 찾아 설치할 수 있습니다. 예를 들어, OpenSim 4.4를 Python 3.10 환경에 설치하려면 다음 명령어를 사용합니다 [6].
  ```bash
  conda install -c opensim-org opensim=4.4=py310np121
  ```
    *   **Moco 포함 패키지 (Windows만 해당):** OpenSim 4.4, 4.4.1, 4.5 버전의 Windows용 Conda 패키지에는 Moco가 포함되어 있습니다. 다음 명령어를 사용하여 설치합니다 [6].
  ```bash
  conda install -c opensim-org opensim-moco
  ```
  최신 OpenSim 버전의 Conda 패키지(Moco 포함)를 사용하는 것이 좋습니다 [6].

#### 2. 수동 설치 (OpenSim 4.3 이상)

OpenSim Python 바인딩을 수동으로 설치할 수도 있지만, 몇 가지 주의사항이 있습니다 [6].

*   GUI 배포판으로 OpenSim 4.3 이상을 설치하는 경우, Python 3.8만 지원됩니다 [6].
*   Conda를 사용하지 않더라도 64비트 Python 버전을 사용해야 합니다 [6].
*   다른 Python 버전으로 수동 설치를 하려면 [소스 코드에서 Python 바인딩을 빌드](https://github.com/opensim-org/opensim-core?tab=readme-ov-file#build-instructions-)해야 합니다 [6].

설치 디렉토리를 `<OPENSIM_INSTALL_DIR>` (Windows: `C:\OpenSim 4.X`, MacOS: `/Applications/OpenSim 4.X`)이라고 가정합니다 [6].

*   **1단계: OpenSim Python 패키지 위치로 이동**
    OpenSim 설치 내의 Python 패키지 위치로 이동합니다. GUI 배포판의 경우 `OPENSIM_INSTALL_DIR/sdk/Python`입니다. 소스 빌드의 경우 Mac/Linux에서 `OPENSIM_INSTALL_DIR/lib/python3.x/site-packages`일 수 있습니다 [6].
*   **2단계: 설치 명령어 실행**
    *   **Windows 사용자 (OpenSim 4.3 이상, Python 3.8):** `setup_win_python38.py` 파일이 존재하는 경우 다음 명령어를 실행합니다 [6].
  ```bash
  python setup_win_python38.py
  ```
    *   **모든 플랫폼:** 다음 명령어를 실행하여 OpenSim Python 바인딩을 설치합니다. Conda 환경이 활성화된 경우, OpenSim이 해당 Conda 환경에 패키지로 설치됩니다 [6].
  ```bash
  python -m pip install .
  ```
*   **3단계: 환경 변수 설정**
    *   **Windows:** `Path` 시스템 환경 변수에 `OPENSIM_INSTALL_DIR/bin` 폴더를 추가하고, 목록의 맨 위로 이동합니다. 변경 사항을 적용하려면 터미널을 재시작해야 합니다 [6].
    *   **Mac:** `DYLD_LIBRARY_PATH` 환경 변수를 OpenSim 및 Simbody 라이브러리를 가리키도록 업데이트해야 할 수 있습니다 [6].
  ```bash
  export DYLD_LIBRARY_PATH=$DYLD_LIBRARY_PATH:<OPENSIM_INSTALL_DIR>/sdk/lib
  export DYLD_LIBRARY_PATH=$DYLD_LIBRARY_PATH:<OPENSIM_INSTALL_DIR>/sdk/Simbody/lib
  ```
  이 명령어를 `~/.bashrc` 또는 다른 터미널 설정 파일에 추가하여 새 터미널을 열 때마다 자동으로 설정되도록 할 수 있습니다 [6].
    *   **Linux:** `LD_LIBRARY_PATH` 환경 변수를 업데이트해야 할 수 있습니다 [6].
  ```bash
  export LD_LIBRARY_PATH=$LD_LIBRARY_PATH:<OPENSIM_INSTALL_DIR>/sdk/lib
  export LD_LIBRARY_PATH=$LD_LIBRARY_PATH:<OPENSIM_INSTALL_DIR>/sdk/Simbody/lib
  ```

#### 3. 오래된 OpenSim 및 Python 버전 설치 (OpenSim 4.2 또는 이전)

OpenSim 4.2 또는 이전 버전을 사용해야 하는 경우, 다음 단계를 따릅니다 [6].

*   **1단계: `PYTHONPATH` 환경 변수 설정**
    *   **Windows:** `PYTHONPATH` 시스템 환경 변수를 `OPENSIM_INSTALL_DIR\sdk\Python`으로 설정합니다 [6].
    *   **Mac/Linux:** 터미널에서 또는 `~/.bashrc` 파일에 다음 명령어를 추가합니다 [6].
  ```bash
  export PYTHONPATH=<OPENSIM_INSTALL_DIR>/sdk/Python:$PYTHONPATH
  ```
*   **2단계: 설치 명령어 실행**
    *   **Windows:** `OPENSIM_INSTALL_DIR/sdk/Python`으로 이동하여 다음 명령어를 실행합니다 (관리자 모드 터미널이 필요할 수 있습니다) [6].
  ```bash
  python setup.py install
  ```
    *   **Mac:** `OPENSIM_INSTALL_DIR/sdk/Python`으로 이동하여 다음 명령어를 실행합니다 [6].
  ```bash
  export DYLD_LIBRARY_PATH=$DYLD_LIBRARY_PATH:<OPENSIM_INSTALL_DIR>/lib
  sudo python setup.py install
  ```
    *   **Linux:** `OPENSIM_INSTALL_DIR/lib/python3.x/site-packages`로 이동하여 다음 명령어를 실행합니다 [6].
  ```bash
  export LD_LIBRARY_PATH=$LD_LIBRARY_PATH:<OPENSIM_INSTALL_DIR>/lib
  sudo python setup.py install
  ```

#### Python 설치 확인

Conda 환경을 활성화하거나 수동으로 설치한 후, 다음 명령어를 실행하여 OpenSim 설치를 테스트합니다 [6].
```python
python
>>> import opensim as osim
>>> osim.GetVersionAndDate()
```
OpenSim 버전과 날짜가 올바르게 출력되면 설치가 성공한 것입니다 [6].

#### Python 스크립팅 추가 정보

*   **Pythonic 확장:** OpenSim Python 인터페이스는 Pythonic한 요소를 포함하고 있습니다. 예를 들어, Python 리스트로 `opensim.Vector` 초기화, 대괄호를 사용한 `VecX` 및 `Vector` 요소 접근, `print`를 사용한 내용 출력, `len()` 함수를 사용한 길이 확인, `model.getForceSet()` 및 `model.getMuscles()`를 통한 세트(Set) 반복 등이 가능합니다 [6].
*   **오류 해결:**
    *   32비트 Python과 64비트 OpenSim 라이브러리를 함께 사용하지 않도록 주의하십시오 [6].
    *   OpenSim의 DLL이 `PATH` 환경 변수에 없는 경우, `set PATH=C:\OpenSim 4.0\bin;%PATH%`와 같은 명령어를 사용하여 추가할 수 있습니다 [6].
    *   macOS에서는 `arm64`와 `intel x86_64` 두 가지 아키텍처가 있으며, GUI 배포판에는 `x86_64` 빌드만 포함됩니다. Homebrew 또는 Anaconda Python을 사용하는 경우, OpenSim을 소스 코드에서 컴파일해야 할 수 있습니다 [6].
