OpenSim에서 Joint Reaction Analysis (JRA)를 수행하기 위한 사전 작업은 다음과 같습니다. JRA는 특정 조인트에서 작용하는 힘과 모멘트를 계산하는 데 사용되는 분석 도구입니다 [1]. 이 분석을 정확하게 수행하려면 모델의 운동학 및 동역학적 일관성이 사전에 확보되어야 합니다.

다음은 JRA를 실행하기 위해 필요한 주요 사전 작업 단계입니다.

**JRA를 위한 사전 작업 단계:**

1.  **OpenSim 모델 (.osim) 준비:**
    *   분석하려는 동작을 수행할 수 있는 유효한 OpenSim 근골격 모델(`.osim` 파일)이 있어야 합니다 [1].
    *   모델은 적절한 세그먼트, 조인트, 근육 및 기타 물리적 특성(질량, 관성 모멘트 등)을 포함해야 합니다.

2.  **마커 데이터 (.trc) 및 외부 하중 데이터 (.mot/.sto 또는 .xml) 준비:**
    *   **마커 데이터 (.trc):** 피험자의 동작을 추적하기 위해 사용된 마커의 3D 위치 데이터 파일이 필요합니다. 이는 Inverse Kinematics (IK)의 입력으로 사용됩니다 [1].
    *   **외부 하중 데이터 (External Loads):** 지면 반력(Ground Reaction Forces, GRF) 및 외부 힘/모멘트 데이터가 필요합니다. 이 데이터는 `.mot` 또는 `.sto` 파일 형식일 수 있으며, OpenSim의 External Loads 설정 파일(`.xml`)을 통해 정의됩니다 [4]. 이 데이터는 Inverse Dynamics (ID) 및 다른 동역학 분석의 필수 입력입니다 [4].
  *   데이터를 OpenSim 모델과 시각적으로 동기화하여 미리 볼 수 있습니다 [2, 4].

3.  **Inverse Kinematics (IK) 수행:**
    *   마커 데이터(`.trc`)를 사용하여 모델의 조인트 각도(운동학)를 계산합니다. 이 결과는 `.mot` 또는 `.sto` 파일로 저장됩니다 [1].
    *   **팁:** IK 결과의 품질은 후속 동역학 분석에 매우 중요합니다. 마커 추적 오류(marker tracking error)가 허용 가능한 수준인지 확인해야 합니다. 일반적으로 좌표계 필터링(예: 6Hz)을 적용하여 노이즈를 줄이는 것이 좋습니다 [4].

4.  **Inverse Dynamics (ID) 또는 Residual Reduction Algorithm (RRA) 수행:**
    *   JRA는 일반적으로 Inverse Dynamics 또는 RRA의 결과물에 의존합니다 [1].
    *   **Inverse Dynamics (ID):** IK에서 얻은 운동학 데이터와 외부 하중 데이터를 사용하여 각 조인트의 순수 조인트 모멘트와 힘을 계산합니다 [1, 4]. ID 결과는 JRA에 직접적인 입력으로 사용될 수 있습니다.
  *   **주의사항:** ID 결과에서 큰 잔여력(residual forces)이나 잔여 모멘트(residual moments)가 나타난다면, 이는 모델 또는 데이터의 불일치를 의미할 수 있습니다. JRA를 실행하기 전에 이러한 잔여력을 최소화하는 것이 중요합니다 [4].
    *   **Residual Reduction Algorithm (RRA):** ID에서 큰 잔여력이 발생하는 경우, RRA를 사용하여 모델의 질량 중심(center of mass) 또는 세그먼트 질량 분포를 조정하고, 잔여 액추에이터(residual actuators)를 사용하여 잔여력을 최소화합니다 [3, 4]. RRA는 잔여력을 줄여 동역학적으로 일관된 운동학을 생성하여 CMC와 JRA의 신뢰도를 높입니다 [4].
  *   RRA는 원하는 운동학을 추적하면서 잔여 액추에이터의 힘을 최소화합니다 [3]. 이 과정에서 모델 조정이 필요할 수 있습니다 [4].
  *   RRA 후에는 잔여 액추에이터의 힘이 체중의 2% 미만인지 확인하는 것이 좋습니다 [4].

5.  **Compute Muscle Control (CMC) (선택 사항):**
    *   근육 활성화 패턴을 추정하고, 잔여력과 보조 모터(joint motors)를 최소화하면서 원하는 운동학을 재현하는 데 사용됩니다 [4].
    *   CMC는 RRA로 조정된 모델과 운동학을 입력으로 사용하여 근육의 기여도를 고려한 동역학적 시뮬레이션을 생성합니다 [4]. CMC 결과 역시 JRA의 입력으로 활용될 수 있습니다.

**요약:**

JRA는 모델의 운동학적, 동역학적 일관성이 확보된 후에 실행해야 합니다. 일반적으로 IK, 외부 하중 데이터 준비, 그리고 ID 또는 RRA/CMC와 같은 동역학 분석을 순서대로 수행하는 것이 표준 워크플로우입니다 [1, 4]. 특히, 잔여력이 최소화된 일관성 있는 동역학 데이터는 JRA 결과의 정확도를 보장하는 데 필수적입니다 [4].

Batch OpenSim Processing Scripts (BOPS)와 같은 도구는 IK, ID, SO, JRA 등의 OpenSim 도구를 배치 처리하여 이러한 워크플로우를 자동화하는 데 도움을 줄 수 있습니다 [5].
