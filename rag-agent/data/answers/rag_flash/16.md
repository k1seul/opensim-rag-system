OpenSim 모델에서 기존 관절의 자유도(Degrees of Freedom, DOF)를 수정하는 것은 `Joint` 객체 내의 `Coordinate` 객체를 변경하는 것을 의미합니다. `Joint`는 두 `Body` 사이의 운동학적 관계를 정의하며, 각 `Joint`는 하나 이상의 `Coordinate`를 포함하며, 이 `Coordinate`의 수가 해당 `Joint`의 자유도를 나타냅니다 [1]. 예를 들어, `PinJoint`는 Z축 회전에 대한 하나의 `Coordinate`를 가집니다 [1].

자유도를 수정하는 방법은 OpenSim GUI, OpenSim API (MATLAB, Python, C++), 또는 `.osim` 파일을 직접 편집하는 방법이 있습니다.

---

### 1. OpenSim GUI를 이용한 관절 자유도 수정 (간단한 속성 변경)

가장 직관적인 방법으로, 기존 `Coordinate`의 속성(예: 범위, 기본값, 잠금 상태)을 변경하는 데 적합합니다.

**단계별 지침:**

1.  **OpenSim GUI에서 모델 로드:** OpenSim 애플리케이션을 실행하고 수정하려는 `.osim` 모델 파일을 엽니다.
2.  **관절 선택:** 내비게이터(Navigator) 창에서 수정하려는 `Joint`를 찾아서 클릭합니다.
3.  **좌표(Coordinate) 속성 편집:** 프로퍼티(Properties) 창에 선택된 `Joint`의 속성 목록이 나타납니다. `Coordinates` 섹션을 확장하면 해당 관절에 속하는 모든 `Coordinate` 객체가 표시됩니다 [1].
    *   각 `Coordinate`를 선택하여 다음 속성을 수정할 수 있습니다:
  *   **`range` (범위):** 관절이 움직일 수 있는 최소 및 최대 각도/변위 값을 설정합니다. (단위: 라디안 또는 미터).
  *   **`default_value` (기본값):** 시뮬레이션 초기 상태에서 관절의 기본 위치를 설정합니다.
  *   **`locked` (잠금):** 이 `Coordinate`를 잠금(true)으로 설정하면 해당 자유도가 비활성화되어 관절이 해당 축을 따라 움직이지 않습니다. 잠금 해제(false)는 자유도를 활성화합니다.
  *   **`prescribed` (고정):** `Coordinate` 값을 시간 함수에 따라 고정할 수 있습니다. `prescribed`가 `true`이면 `prescribed_function`을 정의해야 합니다.
4.  **모델 저장:** 변경 사항을 적용하려면 `File` > `Save Model As...` 또는 `Save Model`을 선택하여 모델을 저장합니다.

### 2. OpenSim API를 이용한 관절 자유도 수정 (스크립트를 통한 제어)

MATLAB, Python 또는 C++와 같은 프로그래밍 환경에서 OpenSim API를 사용하여 모델을 로드하고 `Joint` 및 `Coordinate` 속성을 프로그래밍 방식으로 수정할 수 있습니다. 이는 반복적인 작업이나 복잡한 모델 수정에 유용합니다.

**MATLAB 예시 (Coordinate 범위 및 이름 변경):**

```matlab
% 1. OpenSim 라이브러리 로드 (필요한 경우)
import org.opensim.modeling.*;

% 2. 모델 로드
model = Model('your_model.osim');

% 3. 수정하려는 Joint 객체 가져오기
% 예: 'platformToGround'라는 이름의 PinJoint를 가정
platformToGround = model.getJointSet().get('platformToGround');

% 4. Joint에서 Coordinate 객체 가져오기 및 수정
% PinJoint는 하나의 Coordinate를 가지므로 인덱스 0을 사용 [1].
% upd_coordinates()를 사용하여 쓰기 가능한 Coordinate 객체를 가져옵니다 [3].
platform_rz = platformToGround.upd_coordinates(0);

% 5. Coordinate 속성 설정 [3]
platform_rz.setRange(deg2rad([-100, 100])); % 관절의 회전 범위 설정 (라디안 단위)
platform_rz.setName('platform_rz');  % Coordinate의 이름 설정

% (선택 사항) Coordinate를 잠그거나 기본값 설정
% platform_rz.setLocked(true);
% platform_rz.setDefaultValue(deg2rad(0));

% 6. 수정된 모델 저장
model.print('modified_model.osim');

disp('모델이 성공적으로 수정되어 modified_model.osim으로 저장되었습니다.');
```
**참고:** OpenSim API를 사용할 때는 단위가 킬로그램, 미터, 초로 가정됩니다. 모델을 OpenSim GUI에서 확인하는 것이 좋습니다 [3].

### 3. `.osim` XML 파일을 직접 편집 (고급 사용자용)

`.osim` 파일은 XML 형식으로 작성되어 있으므로 텍스트 편집기에서 직접 열어 수정할 수 있습니다. 이 방법은 XML 구조에 대한 이해가 필요하며 오류가 발생하기 쉽습니다 [4].

**단계별 지침:**

1.  **`.osim` 파일 백업:** 원본 모델 파일의 손상을 방지하기 위해 항상 백업 사본을 만드십시오.
2.  **텍스트 편집기로 파일 열기:** 메모장, VS Code, Sublime Text 등과 같은 텍스트 또는 XML 편집기로 `.osim` 파일을 엽니다.
3.  **해당 `Joint` 및 `Coordinate` 태그 찾기:**
    *   `<JointSet>` 섹션에서 수정하려는 `Joint` (예: `<PinJoint name="platformToGround">`)를 찾습니다.
    *   해당 `Joint` 태그 내에서 `<coordinates>` 섹션을 찾고 수정하려는 `<Coordinate>` (예: `<Coordinate name="platform_rz">`)를 찾습니다.
4.  **속성 값 수정:** `Coordinate` 태그 내의 속성 값(예: `<range>`, `<default_value>`, `<locked>`)을 직접 수정합니다.
    ```xml
    <PinJoint name="platformToGround">
  ...
  <coordinates>
  <Coordinate name="platform_rz">
  <range>-1.7453292519943295 1.7453292519943295</range> <!-- 라디안으로 변경된 범위 -->
  <default_value>0</default_value>
  <locked>false</locked>
  ...
  </Coordinate>
  </coordinates>
  ...
    </PinJoint>
    ```
5.  **파일 저장:** 변경 사항을 저장하고 OpenSim GUI에서 로드하여 올바르게 적용되었는지 확인합니다.

### 4. 관절 자유도 추가 또는 제거 (고급 모델링)

기존 `Coordinate`의 속성을 변경하는 것을 넘어, 관절의 실제 자유도 수를 변경하려면 다음 방법들을 고려해야 합니다.

*   **관절 유형 변경:**
    *   단순한 `PinJoint` (1 DOF)를 `UniversalJoint` (2 DOF) 또는 `BallJoint` (3 DOF)와 같은 더 많은 자유도를 가진 다른 내장 `Joint` 유형으로 교체해야 할 수 있습니다.
    *   이는 `.osim` 파일에서 `PinJoint` 태그를 적절한 `Joint` 유형 태그로 바꾸고 필요한 `Coordinate` 정의를 추가하는 것을 의미합니다.
*   **`CustomJoint` 사용:**
    *   `CustomJoint`를 사용하면 원하는 수의 자유도와 각 자유도의 회전/변환 축을 직접 정의할 수 있습니다 [6]. 이는 특정 생체역학적 관절(예: 3 DOF 무릎 관절)을 모델링할 때 유용합니다 [5].
    *   `CustomJoint`는 `SpatialTransform`을 사용하여 여러 `Coordinate`를 정의하고 각 `Coordinate`가 어떤 변환(회전 또는 병진)을 나타내는지 지정합니다.
*   **`CoordinateCouplerConstraint` 사용:**
    *   이것은 직접적인 DOF 추가/제거는 아니지만, 하나의 `Coordinate`의 움직임을 다른 `Coordinate`의 함수로 만들어 모델의 *독립적인* 자유도 수를 줄일 수 있습니다 [2]. 예를 들어, 슬개골의 움직임을 무릎 각도의 함수로 모델링하는 데 사용될 수 있습니다 [2].

**실용적인 조언:**

*   **모델 백업:** 중요한 모델을 수정하기 전에는 항상 원본 파일을 백업하십시오.
*   **단위 확인:** OpenSim은 기본적으로 SI 단위(kg, m, s)를 사용합니다 [3].
*   **GUI에서 확인:** 수정 후에는 항상 OpenSim GUI에서 모델을 로드하여 변경 사항이 의도한 대로 적용되었는지 시각적으로 확인하십시오. 특히 관절의 범위나 위치가 올바른지 확인하는 것이 중요합니다.
*   **오류 메시지:** `.osim` 파일을 직접 편집하는 경우, XML 구문 오류는 모델 로드 실패로 이어질 수 있으므로 OpenSim 콘솔의 오류 메시지를 주의 깊게 확인하십시오.
