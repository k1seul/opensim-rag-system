안녕하세요. OpenSim 전문가로서 모델 스케일링(Scaling)에 필요한 파일에 대해 정확하고 상세하게 안내해 드리겠습니다.

OpenSim에서 `Scale Tool`을 사용하여 모델을 스케일링하기 위해서는 몇 가지 필수 파일과 선택적으로 사용할 수 있는 파일들이 필요합니다 [2]. 이 파일들은 스케일링 설정 파일(.xml)에 지정하여 사용합니다 [3].

### 필수 파일 (Required Files)

1.  **일반(Generic) 근골격 모델 파일 (`.osim`)**
    *   **설명:** 스케일링의 기반이 되는 기본 모델입니다 [3, 5]. 예를 들어, `gait2354_simbody.osim`과 같이 OpenSim에서 제공하는 모델이나 사용자가 직접 수정한 모델일 수 있습니다. 이 모델의 인체 측정학적 정보(anthropometry)가 피험자의 데이터에 맞게 조정됩니다 [2].

2.  **정적 자세 마커 데이터 파일 (`.trc`)**
    *   **설명:** 피험자가 특정 정적 자세(예: 양팔을 벌리고 서 있는 자세)를 취하고 있을 때 측정한 실험적 마커의 3차원 좌표 데이터입니다 [5].
    *   **용도:**
  *   모델의 각 신체 분절(segment)에 적용할 스케일 팩터(scale factor)를 계산하는 데 사용됩니다 [5].
  *   모델 상의 가상 마커(virtual marker) 위치를 실험 데이터의 마커 위치와 일치시키기 위해 모델의 자세를 잡는(pose) 데 사용됩니다 [5].

### 선택적 파일 (Optional Files)

1.  **마커 세트 파일 (`MarkerSet`, `.xml`)**
    *   **설명:** 모델에 부착된 가상 마커의 이름과 위치를 정의하는 외부 파일입니다 [3].
    *   **용도:** 만약 `.osim` 모델 파일 내에 `<MarkerSet>`이 정의되어 있지 않거나, 별도의 마커 세트를 적용하고 싶을 때 사용합니다 [5].

2.  **좌표 데이터 파일 (`.mot`)**
    *   **설명:** 정적 자세 동안의 모델 관절 각도(joint angles) 데이터입니다 [5].
    *   **용도:** `Scale Tool`은 내부적으로 역기구학(Inverse Kinematics)을 사용하여 모델의 자세를 정적 데이터에 맞춥니다. 만약 기본 자세가 실험 자세와 너무 다를 경우, 이 `.mot` 파일을 제공하여 역기구학 솔버가 더 정확한 초기 자세를 찾는 데 도움을 줄 수 있습니다 [5].

| :--- | :--- | :--- | :--- |

| 정적 마커 데이터 | `.trc` | 스케일 팩터 계산 및 자세 정렬을 위한 실험적 마커 위치 데이터 [2, 5]. | **필수** |

### 실용적인 조언 및 모범 사례

*   **스케일링 설정 파일 (`Scale Setup File`, `.xml`):** 위의 모든 입력 파일과 스케일링 관련 설정(예: 질량 보존 여부, 스케일링 방식 등)은 하나의 설정 파일에 정의됩니다 [3]. OpenSim GUI의 `Tools -> Scale Model...` 메뉴를 통해 설정을 지정하고 `.xml` 파일로 저장할 수 있습니다 [5].
*   **질량 분포 보존 (`Preserve mass distribution`):** 이 옵션을 활성화하면, 스케일링된 모델의 총질량이 피험자의 질량과 같아지도록 조정되며 각 신체 분절의 질량 비율은 기존 모델과 동일하게 유지됩니다 [1, 5]. 비활성화하면 각 분절의 부피 변화에 따라서만 질량이 스케일링되어 모델의 총질량이 피험자 질량과 일치하지 않을 수 있습니다 [5]. 일반적으로 이 옵션을 활성화하는 것을 권장합니다.
*   **출력 파일 확인:** 스케일링이 성공적으로 완료되면 주로 두 가지 파일이 생성됩니다.
    1.  **스케일링된 모델 파일 (`_scaled.osim`):** 피험자의 신체 크기에 맞게 조정된 새로운 모델 파일 [1, 3].
    2.  **스케일 팩터 파일 (`ScaleSet.xml`):** 각 신체 분절에 적용된 스케일 팩터들을 저장한 파일 [1, 3]. 이 파일은 디버깅이나 스케일링 과정 검토에 유용합니다.
