안녕하세요. OpenSim 전문가 및 기술 가이드입니다. OpenSim에서 .c3d 파일을 .trc 파일로 변환하는 방법에 대해 정밀하고 실행 가능한 답변을 드리겠습니다.

OpenSim의 역운동학(Inverse Kinematics)과 같은 도구들은 마커 궤적 데이터를 `.trc` 파일 형식으로 입력받습니다 [2, 3]. 따라서 모션 캡처 시스템에서 생성된 `.c3d` 파일은 OpenSim에서 사용하기 전에 `.trc` 파일로 변환하는 과정이 필수적입니다 [2]. 변환을 위한 주요 방법은 다음과 같습니다.

### 방법 1: MATLAB 스크립트 사용 (권장)

OpenSim 4.0부터 MATLAB 인터페이스를 통해 `.c3d` 파일을 직접 읽고 `.trc` 및 `.mot` 파일로 변환하는 기능이 공식적으로 지원됩니다 [1]. 이 방법은 데이터 처리 과정을 자동화하고 대량의 데이터를 일관성 있게 처리하는 데 가장 효과적입니다.

**준비 사항:**
*   PC에 OpenSim이 설치되어 있어야 합니다.
*   OpenSim과 MATLAB 연동 설정이 완료되어 있어야 합니다 [1].

**단계별 절차:**

1.  **MATLAB 실행 및 OpenSim 라이브러리 로드:**
    MATLAB을 시작하고, OpenSim API를 사용하기 위해 스크립트 상단에 라이브러리를 `import`하는 코드를 추가합니다.

2.  **`C3DFileAdapter` 객체 생성 및 파일 읽기:**
    `C3DFileAdapter`는 `.c3d` 파일을 읽기 위한 OpenSim의 유틸리티입니다 [1]. 이 어댑터를 사용하여 대상 `.c3d` 파일을 읽습니다.

3.  **마커 데이터 테이블(Table) 추출:**
    읽어온 데이터 구조에서 마커 데이터에 해당하는 테이블을 가져옵니다.

4.  **`TRCFileAdapter`를 이용한 `.trc` 파일 저장:**
    `TRCFileAdapter`를 사용하여 추출한 마커 테이블을 `.trc` 파일 형식으로 디스크에 씁니다.

**예제 MATLAB 코드:**

```matlab
% 1. OpenSim 라이브러리 import
import org.opensim.modeling.*;

% 2. 변환할 .c3d 파일의 전체 경로를 지정합니다.
c3d_filepath = 'C:\MyData\subject01_walk.c3d';

% 3. C3DFileAdapter를 사용하여 파일을 읽습니다.
c3d_adapter = C3DFileAdapter();
tables = c3d_adapter.read(c3d_filepath);

% 4. 마커 데이터 테이블을 가져옵니다.
markers_table = c3d_adapter.getMarkersTable(tables);

% 5. 저장할 .trc 파일의 경로와 이름을 지정합니다.
output_trc_filepath = 'C:\MyData\subject01_walk.trc';

% 6. TRCFileAdapter를 사용하여 .trc 파일로 저장합니다.
trc_adapter = TRCFileAdapter();
trc_adapter.write(markers_table, output_trc_filepath);

disp(['성공: ' c3d_filepath ' 파일이 ' output_trc_filepath ' 파일로 변환되었습니다.']);
```

**실용적인 조언:**

*   **마커 이름 확인:** 변환 후 `.trc` 파일 헤더에 있는 마커 이름들이 사용하려는 OpenSim 모델(`.osim` 파일)의 마커 이름과 정확히 일치하는지 반드시 확인해야 합니다 [2, 3]. 이름이 다를 경우 역운동학(Inverse Kinematics) 과정에서 오류가 발생합니다.
*   **OpenSim 버전:** OpenSim 4.2 이상 버전은 `ezc3d` 라이브러리를 사용하여 Kistler(Type-3) 포스 플레이트 데이터도 지원합니다 [1]. 이전 버전은 AMTI 및 Bertec(Type-2) 포스 플레이트만 지원하는 제한이 있었습니다 [1].
*   **예제 스크립트:** OpenSim 설치 폴더 내 `CodeExamples` 디렉터리에 있는 `c3dExport.m` 예제 스크립트를 참고하면 더 자세한 활용법을 확인할 수 있습니다 [2, 3].

### 방법 2: 온라인 변환 도구 사용

MATLAB 환경이 없거나, 소수의 파일을 빠르고 간단하게 변환하고 싶을 때 유용한 방법입니다.

**단계별 절차 (C3Dtools.com 사용 예시):**

1.  웹 브라우저에서 [C3Dtools.com](https://c3dtools.com/)에 접속합니다 [6].
2.  웹사이트에 변환하려는 `.c3d` 파일을 업로드합니다.
3.  내보내기(Export) 옵션에서 **TRC** 형식을 선택합니다 [6].
4.  변환이 완료되면 생성된 `.trc` 파일을 다운로드합니다.

**장점:**
*   별도의 소프트웨어 설치 없이 웹 브라우저만으로 변환이 가능하여 편리합니다.

**단점:**
*   데이터 전처리(필터링, 잘라내기 등)에 대한 세부적인 제어가 제한적일 수 있습니다.
*   대규모 데이터의 일괄 처리나 자동화된 워크플로우에 적용하기는 어렵습니다.
