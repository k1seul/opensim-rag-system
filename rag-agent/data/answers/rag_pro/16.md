안녕하세요. OpenSim 전문가 및 기술 가이드입니다. OpenSim 모델의 관절 자유도(DOF, Degree of Freedom)를 수정하는 방법에 대해 문의하셨습니다.

OpenSim에서 관절 자유도를 수정하는 방법은 크게 두 가지로 나눌 수 있습니다: (1) 기존 자유도의 운동 범위를 조절하는 방법과 (2) 새로운 자유도를 추가하는 방법입니다. 각 목적에 맞는 절차를 아래에 단계별로 설명하겠습니다.

### 1. 기존 자유도(DOF)의 운동 범위 조절하기

기존 관절의 운동 범위를 넓히거나 좁혀야 할 때 사용하는 방법입니다 [4]. 예를 들어, 특정 장애를 시뮬레이션하기 위해 운동 범위를 제한하거나, 모델이 실험 데이터의 움직임을 따라가지 못할 때 운동 범위를 확장해야 할 수 있습니다 [4].

**단계별 지침 (OpenSim GUI 사용):**

1.  **관절(Joint) 찾기:** OpenSim GUI의 네비게이터(Navigator) 창에서 수정하고자 하는 자유도가 포함된 관절을 찾습니다 [4]. 예를 들어, `gait2392` 모델의 골반 회전(`pelvis_tilt`)을 수정하려면 `ground_pelvis` 관절을 선택합니다 [4].
2.  **CoordinateSet 열기:** 네비게이터에서 해당 관절을 선택한 상태로, 속성(Property) 창에서 `CoordinateSet` 속성을 찾습니다. 속성 값 옆에 있는 `...` 버튼을 클릭하여 `CoordinateSet` 창을 엽니다 [4].
3.  **수정할 좌표(Coordinate) 선택:** `CoordinateSet` 창이 열리면, `objects` 목록에서 수정하려는 자유도에 해당하는 `Coordinate`를 찾습니다 [4].
4.  **범위(Range) 수정:** 해당 `Coordinate`를 확장하여 `range` 폴더를 찾습니다 [4].
    *   `[0]` 값은 최소 운동 범위를 나타냅니다 [4].
    *   `[1]` 값은 최대 운동 범위를 나타냅니다 [4].
    *   이 값들을 더블 클릭하여 원하는 값으로 수정합니다. **주의: 각도 값은 반드시 라디안(radians) 단위로 입력해야 합니다** [1, 4].
5.  **저장 및 새로고침:** 수정한 모델을 저장한 뒤, GUI에서 모델을 다시 불러오면 변경 사항이 시각적으로 적용된 것을 확인할 수 있습니다 [1, 4].

### 2. 새로운 자유도(DOF) 추가하기

모델이 좌표계 원점에 고정되어 있을 때, 시뮬레이션을 위해 모델이 자유롭게 움직이도록 새로운 자유도를 추가해야 하는 경우가 있습니다 [1, 4]. 일반적으로 3개의 병진(translation) 자유도와 3개의 회전(rotation) 자유도, 총 6개의 자유도를 추가해야 합니다 [3].

**단계별 지침 (.osim 파일 텍스트 편집기 사용):**

1.  **대상 바디(Body) 확인:** 모델의 `ground`에 관절로 연결된 바디를 찾습니다. 하체 모델의 경우 주로 `pelvis`이고, 상체 모델의 경우 `torso`인 경우가 많습니다 [3, 4].
2.  **.osim 파일 열기:** 해당 모델의 `.osim` 파일을 Notepad++와 같은 텍스트 편집기에서 엽니다 [3, 4].
3.  **관절(Joint) 위치 찾기:** 파일 내에서 다음 경로를 따라 1단계에서 확인한 바디의 관절 정의 부분을 찾습니다 [1, 3]:
    `OpenSimDocument` -> `Model` -> `BodySet` -> `Objects` -> `Body name="pelvis"` (예시) -> `Joint`
4.  **기존 관절 제거:** 해당 바디와 `ground`를 연결하는 기존 `<Joint>`와 `</Joint>` 사이의 모든 내용을 삭제합니다 [3, 4].
5.  **새로운 6자유도 관절 추가:** 삭제한 위치에 `FreeJoint`와 같이 6자유도를 정의하는 XML 코드를 붙여넣습니다. `FreeJoint`는 3개의 회전 좌표(`pelvis_tilt`, `pelvis_list`, `pelvis_rotation`)와 3개의 병진 좌표(`pelvis_tx`, `pelvis_ty`, `pelvis_tz`)를 자동으로 생성합니다.

### 실용적 조언 및 모범 사례

*   **정확성 검증:** 관절의 운동 범위를 수정한 후에는 모델이 변경된 범위 내에서도 여전히 정확한 결과를 제공하는지 반드시 확인해야 합니다 [4].
*   **문헌 참조:** 모델의 좌표 운동 범위를 변경하기 전에, 해당 모델과 관련된 문헌을 참고하여 모델의 제한 사항을 파악하는 것이 좋습니다 [4].
*   **단위 확인:** OpenSim의 기본 단위는 미터(m), 킬로그램(kg), 초(s), 라디안(rad)입니다 [2]. 값을 수정할 때 올바른 단위를 사용하고 있는지 항상 확인하십시오.
*   **자유도의 수:** 관절의 자유도(DOF) 수는 해당 관절에 포함된 `Coordinate` 객체의 수와 같습니다 [2, 6]. 새로운 자유도를 추가한다는 것은 새로운 `Coordinate`를 정의하는 것과 같습니다.
