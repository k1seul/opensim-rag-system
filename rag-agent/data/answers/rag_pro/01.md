네, OpenSim 전문가로서 Python과 MATLAB 환경에서 OpenSim 스크립팅을 설정하는 방법을 단계별로 정확하게 안내해 드리겠습니다.

### 1. MATLAB 환경 설정

OpenSim 4.0 이상 버전은 64비트 MATLAB이 필요합니다 [3]. 설치 전에 MATLAB 버전을 확인해 주세요 [2, 3].

**단계별 지침:**

1.  **MATLAB 실행:** MATLAB을 실행합니다 [3]. Windows 사용자의 경우, 이전에 OpenSim 3.x 버전을 설정한 경험이 있다면 MATLAB 아이콘을 마우스 오른쪽 버튼으로 클릭하여 '관리자 권한으로 실행'하는 것이 좋습니다 [3].

2.  **경로 변경:** MATLAB의 '현재 폴더(Current Folder)'를 OpenSim MATLAB 스크립트 디렉토리로 변경합니다 [3]. Windows의 기본 경로는 다음과 같습니다 [1, 3]:
    `C:/Users/<사용자이름>/Documents/OpenSim/4.0/Code/Matlab`

3.  **설정 스크립트 실행:** 현재 폴더에서 `configureOpenSim.m` 파일을 실행합니다 [1, 3].
    ```matlab
    configureOpenSim
    ```

4.  **OpenSim 설치 디렉토리 선택:** 스크립트를 실행하면 OpenSim 설치 디렉토리를 선택하라는 창이 나타납니다 [1, 3]. 일반적으로 Windows의 기본 설치 경로는 `C:/OpenSim 4.0` 입니다 [1, 3].

5.  **시스템 PATH 환경 변수 설정 (Windows 사용자):**
    *   설정이 성공적으로 완료되면 알림창이 나타납니다 [1].
    *   **매우 중요한 단계:** Windows 사용자는 OpenSim 설치 폴더 내의 `bin` 디렉토리(예: `C:/OpenSim 4.0/bin`)가 시스템의 `PATH` 환경 변수에 추가되어 있는지 확인해야 합니다 [1]. 만약 다른 버전의 OpenSim이 설치되어 있다면, 현재 사용하려는 버전의 경로가 다른 버전보다 앞에 위치해야 합니다 [1].

6.  **MATLAB 재시작:** `PATH` 변수 설정 등 모든 변경 사항이 적용되려면 MATLAB을 재시작해야 합니다 [1]. OpenSim 라이브러리는 재시작 후에 인식됩니다 [1].

7.  **설정 확인:** MATLAB을 재시작한 후, 아래 명령어를 커맨드 창에 입력하여 OpenSim 라이브러리가 성공적으로 로드되었는지 테스트합니다. 오류가 발생하지 않으면 설정이 완료된 것입니다.
    ```matlab
    import org.opensim.modeling.*
    model = Model();
    disp('OpenSim-Matlab integration is successful.');
    ```

### 2. Python 환경 설정

Python 환경 설정은 Conda 패키지 매니저를 사용하는 것이 가장 쉽고 권장되는 방법입니다 [4].

**단계별 지침:**

1.  **Anaconda 또는 Miniconda 설치:** 컴퓨터에 Anaconda 또는 Miniconda가 설치되어 있지 않다면 먼저 설치합니다.

2.  **Anaconda Prompt 실행:** Anaconda Prompt (또는 터미널)를 실행합니다.

3.  **Conda를 이용한 OpenSim 설치:** 다음 명령어를 입력하여 `opensim-org` 채널에서 OpenSim 패키지를 설치합니다 [4].
    ```bash
    conda install -c opensim-org opensim
    ```
    이 명령어는 OpenSim 라이브러리와 Python 바인딩을 포함하는 새로운 Conda 환경을 생성하거나 기존 환경에 설치합니다.

4.  **설정 확인:** 설치가 완료되면 Python을 실행하여 OpenSim 패키지를 임포트하고 버전을 확인하는 코드로 설정을 테스트할 수 있습니다.
    ```python
    import opensim

    # OpenSim 버전 정보 출력
    print(opensim.GetVersionAndDate())

    # 간단한 모델 객체 생성 테스트
    model = opensim.Model()
    print('OpenSim-Python integration is successful.')
    ```

---
**실용적인 조언:**

*   **MATLAB:** `configureOpenSim.m` 스크립트는 `userpath.m` 파일에 OpenSim 경로를 추가합니다. 스크립트 실행에 문제가 발생하면 이 파일의 권한 문제이거나, MATLAB 경로 캐시 문제일 수 있습니다. 이 경우 `rehash path` 명령어를 실행해 보세요.
*   **Python:** Conda를 사용하면 의존성 문제를 자동으로 해결해주므로 매우 편리합니다 [4]. 특정 프로젝트를 위해 별도의 Conda 환경(`conda create --name my_opensim_env`)을 만들어 OpenSim을 설치하면 다른 Python 프로젝트와의 충돌을 방지할 수 있습니다.
*   **API 문서:** 더 심층적인 개발이나 API의 구조를 이해하고 싶다면 OpenSim API 가이드를 참고하는 것이 좋습니다 [5]. API는 C++뿐만 아니라 MATLAB과 Python 사용자에게도 유용한 정보를 제공합니다 [5].
